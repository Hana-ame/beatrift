# PLAYTEST 联调指南

## 环境准备

- PC 与手机同一局域网(WiFi)。
- PC 打开游戏 URL(开发: `http://localhost:5173/`; 部署: 以实际 Pages 域名为准)。**注意: 真机陀螺仪需要 HTTPS**(本地可用自签名/隧道)。
- 手机浏览器访问同一 URL(可扫 PC 屏幕上的二维码)。

## 桌面自测(无手机)

同一浏览器开两个标签:

1. `#/pc` → 记录房间码。
2. `#/mobile?sim=1` → 手输房间码 → 点「加入」→ 校准 → 进入遥控界面(模拟器会每秒挥舞)。
3. 回 PC 标签点「开始游戏」→ 观察音符被击中/漏击。

## 真机联调步骤

1. **PC**: 进入 → 选「我是 PC 显示器」→ 生成房间, 等待连接。
2. **Mobile**: 选「我是手机控制器」→ 从列表点房间, 或扫码/输码。
3. **校准**: 手机竖直举在身前(屏幕朝向自己、顶边朝上), 点「开始校准」→ 目视屏幕保持约 2 秒 → 「校准完成」→ 点「进入游戏」。
   - iOS 首次会弹陀螺仪权限请求, 需允许。
   - 握持姿势不对可随时「重新校准」。
4. **开始**: PC 点「开始游戏」。音乐响起, 音符按手写谱面(`public/charts/default.json`)沿判定平面飞向玩家。
5. **击打**: 像挥光剑一样快速转动手机把音符击回。击打时刻 = 音符接近胸前时。有震动反馈。
6. 漏击 3 次结束, PC 显示分数面板。

## 调试建议

| 症状 | 排查 |
|------|------|
| Mobile 列表为空 | MQTT 公共 broker 偶发慢; 直接手输房间码(PeerJS 不依赖 MQTT) |
| 连不上/超时 | PeerJS 公共云不可达, 已自动重试; 换网络重试; 房间码与 peerId 要一致(`beatrift-{code}`) |
| 剑方向反了/左右反 | 轴符号因机型而异, 调 `src/motion/sensor.js` 中 `_onMotion` 的陀螺仪/加速度计符号 |
| 剑缓慢漂移 | Mahony 融合偏航参考重力方向, 时间久了会缓慢漂移; 重新校准即可 |
| 命中率极低 | 挥击要「快+准」, 窗口约 ±150ms; 先练习挥到位再加快 |
| 判定太严 | 调 `src/constants.js` 的 `DIFFICULTY`(`hitRadius` / `hitSteps`) |
| 剑身看不到 | 方向已强制屏幕平面内; 若仍异常, 重新校准基准再试 |
| 校准后方向不对 | 校准时手机要稳定对准屏幕中心 2 秒, 别在摆动手持状态校准 |
| e2e 偶发 12/13 (MQTT 发现失败) | 公共 HiveMQ broker 偶发 WS 握手失败(环境问题, 非代码); 已内建 3 次重试, 重跑即过 |

## 体感说明(2026-08 新版)

- **方向解算**: `devicemotion` 加速度计+陀螺仪 → **Mahony 互补滤波** → 姿态四元数 → **拍面方向(屏幕法线)** `forward`(世界系 z 向上、不依赖罗盘 alpha)。四元数融合避免竖立/平放位 deviceorientation 的读数不稳。
- **单点基准校准**: 手机前端瞄准 PC 屏幕中心、静止保持约 2 秒, 采样平均姿态四元数记为基准 `ref`。
- **连续映射**: 实时 Mahony 四元数解出的 `forward` 相对 `ref` 的偏移 `screenRel` → 屏幕平面连续坐标 `(u,v)` → 放大 `GAIN=2.5` → 光剑方向。
  - 方向强制 `dir.z=0`(屏幕平面内): 中性位竖直向上, u 控左右倾斜(±50°), v 控上下摆动, 剑刃始终可见。
- 角速度跳变 >90°/s 视为异常, 丢弃该帧防抖。
- 手持不看屏幕, 像拿球拍一样挥手机即可。

## 校准步骤(真机)

1. 连接后先选难度(简单/普通/困难)。
2. 点「开始校准」→ 授权传感器(加速度计+陀螺仪)。
3. **单点基准**: 手机前端(握光剑式)瞄准 PC 屏幕中心, 静止保持约 2 秒(进度条走满自动完成)。
4. 「校准完成」→ 点「进入游戏」。
5. 游玩时实时 forward 相对该基准连续映射为光剑方向, 全程无网格量化。

> 握持姿势不对可点「重新校准」整体重来。

## 难度选择(校准屏)

校准界面可选择 简单 / 普通 / 困难, 随 `READY` 发给 PC, 影响:
- 判定半径(`hitRadius`)与节拍窗口(`hitSteps`): 越大越容易中
- 手机挥击触发灵敏度(`swingPeak`/`swingMin`): 越低越容易触发挥击

## 无敌模式

`src/constants.js` 中 `GAME.INVINCIBLE = true`: 漏击不断命、不结束, 生命显示 ∞, 可无限玩。
游戏结束面板通过 PC 屏幕右上角「退出」按钮调出。

## 性能提示

- PC 渲染: WebGL, 关掉其它重 GPU 标签。
- 手机: 只发陀螺仪数据, 屏幕可熄(AudioContext 保持); 关闭省电模式避免降频。
