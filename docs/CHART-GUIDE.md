# 谱面编写指南（BeatMap）

谱面支持 JSON 数组或带歌曲元信息的对象格式 `{ song: { name, bpm, synth, url? }, notes: [...] }`。
内置四张谱面：`public/charts/default.json`、`public/charts/song1.json`（霓虹脉冲 128 BPM）、`public/charts/song2.json`（激光冲刺 150 BPM）、`public/charts/song3.json`（深空回响 96 BPM）。

## 文件格式

```json
{
  "song": { "name": "霓虹脉冲", "bpm": 128, "synth": "pulse" },
  "notes": [
    { "beat": 8,    "x": -0.8, "y": 1.1 },
    { "beat": 14.5, "x": 1.5,  "y": 2.1, "type": "chain" },
    { "beat": 16,   "x": 0,    "y": 2.2, "type": "gold" },
    { "beat": 30.5, "x": -2.2, "y": 0.8, "type": "bomb" }
  ]
}
```

每个音符一个对象，包含以下字段：

| 字段 | 含义 | 建议范围 |
|------|------|----------|
| `beat` | 音符**到达判定平面的拍数**（严格递增，避免同拍重叠） | 从 `8` 开始留出准备时间，按 `0.5`/`1` 拍步进 |
| `x` | 判定平面上的**水平**位置（世界 X） | `-2.6 ~ 2.6` |
| `y` | 判定平面上的**垂直**高度（世界 Z，z-up，越大越高） | `0.5 ~ 2.8` |
| `type`（可选） | 音符类型：`normal`（默认）/ `gold`（黄金星核，双倍得分+回盾+高额 Fever）/ `chain`（高速连斩流）/ `bomb`（裂隙炸弹，误触扣盾断连，避开加分） | 按乐句高潮与刀流编排 |
| `color`（可选） | 自定义颜色（`0xRRGGBB`） | 省略时按类型与 `x` 坐标自动配色 |

## 判定、难度与平衡设计

- **纯接触判定（与挥动速度解耦）**：剑刃线段（枢轴→剑尖）与判定平面投射到音符距离 ≤ `effectiveHitRadius` 即命中。
- **四档难度平衡**（`src/constants.js`）：
  - **简单 (Easy)**：半径 `1.55`、窗口 `±5.5 step`、飞行速度 `0.85x`、护盾 `5♥`、得分倍率 `0.85x`
  - **普通 (Normal)**：半径 `1.25`、窗口 `±4.5 step`、飞行速度 `1.0x`、护盾 `4♥`、得分倍率 `1.0x`
  - **困难 (Hard)**：半径 `1.02`、窗口 `±3.5 step`、飞行速度 `1.2x`、护盾 `3♥`、得分倍率 `1.25x`
  - **大师 (Master)**：半径 `0.85`、窗口 `±2.6 step`、飞行速度 `1.38x`、护盾 `3♥`、得分倍率 `1.5x`
- **连击倍率与 FEVER 爆发**：
  - 连击阶梯倍率：`10+` (`1.5x`)、`20+` (`2.0x`)、`30+` (`3.0x`)、`50+` (`4.0x`)。
  - **FEVER 过载**：命中积累能量至 `100%` 自动激活 `8` 秒 FEVER，全倍率翻倍（最高 `8.0x`），判定半径加成 `+15%`，光剑与音轨切换黄金过载特效。
